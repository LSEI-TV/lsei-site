**« webtvspectateur »** (au singulier) / **« webtvspectateurs »** (au pluriel) : terme **créé par LSEI** pour désigner les spectateurs de la web TV. À CONSERVER tel quel — ne pas le corriger, le remplacer (« téléspectateurs », « visiteurs »…) ni le scinder. Orthographe : un seul mot, tout en minuscules, sans trait d'union.

Contexte : LSEI = Le Sport en Image, web TV associative sportive ([[lsei-new-site]]).
